# 开源运行与合规说明

## 定位与边界

本仓库是 A 股市场观察、企业信息阅读与研究候选筛选工具。它输出可核验的事实、来源、时间、数据缺口和程序计算结果；不提供买卖指令、收益承诺、自动交易或个性化投资建议。

所有公开输出应保留：

- `schemaVersion`：调用方据此兼容输出结构；
- `sourceMeta`：来源、抓取时间、实时/缓存/离线示例状态；
- `dataGaps`：缺失或降级原因；
- `scope`：能力边界与非投资建议说明。

## 使用方式

### 1. 本地 MCP stdio

适合 Codex、Claude Desktop、Cherry Studio 等支持本地 MCP 的客户端。

```bash
npm ci
Copy-Item .env.example .env # Windows；Linux/macOS 用 cp
npm run mcp:stdio
```

客户端配置可参考 [examples/mcp/mcp.json](../examples/mcp/mcp.json)。`stdio` 协议要求 stdout 只能输出协议数据，因此运行日志会写到 stderr。

### 2. Streamable HTTP MCP

启动完整服务后使用 `http://localhost:8080/api/mcp`。该模式可复用完整应用的市场观察、个股事实快照和条件筛选提供器；适合团队、远程 Agent 或公网反向代理部署。

### 3. CLI

```bash
npm run cli -- market
npm run cli -- quote 002230
npm run cli -- search 科大讯飞
npm run cli -- snapshot 002230
npm run cli -- screen "ROE 大于 15%，净利润连续增长的 A 股"
```

CLI 只输出 JSON，适合 shell 脚本、Cron、Notebook 和其他程序消费。未配置数据源时，使用 `--offline` 可得到 fixtures，不会发起网络请求。

### 4. HTTP API / 容器运行

```bash
Copy-Item .env.example .env
# 编辑 .env：至少替换 POSTGRES_PASSWORD；AI 与妙想能力按需填写。
docker compose -f docker-compose.open-source.yml up --build
```

访问 `GET /health` 确认进程与数据库状态，访问 `GET /api/health/sources` 查看服务进程已观测到的数据源状态。后者不会主动触发第三方调用，因此不会消耗 API 配额。

## 分层架构

```text
CLI / stdio MCP / HTTP MCP / HTTP API
                ↓
      稳定输出契约（schema、来源、缺口、边界）
                ↓
       事实快照与确定性计算（shared/）
                ↓
数据源适配器（行情、财报、公告、搜索、筛选、社媒）
                ↓
缓存、重试、限流、超时、来源健康状态

AI 解读（可选）只读取已完成事实与证据，不能覆盖确定性结果。
```

当前公共 CLI/stdio MCP 使用 `backend/dataSources/publicMarket.ts` 的 Node 原生行情与搜索适配器；`backend/core/` 负责市场观察和最小事实快照组合；完整财务、技术、公告事实快照由 HTTP 服务中的研究管线提供。新增数据源时，应先在适配器层输出来源、时点和失败状态，再接入事实计算，最后才允许 AI 解释使用。

## 数据源与第三方限制

- 公开接口、网页端接口和免费数据源可能限流、变更、停服或限制商用；必须在自己的环境中确认其当前服务条款、robots 规则、许可和地域限制。
- 巨潮、交易所公告及权威媒体可作为事实核验来源；社区、社媒和搜索快照仅应作为舆情或待核验线索，不能直接升级为事实事件。
- 不应把第三方原文、用户数据、Cookie、Access Secret、API Key 或付费数据重新发布到仓库、日志或 MCP 返回值。
- `MX_APIKEY`、`ZHIHU_ACCESS_SECRET`、GLM/DeepSeek Key、数据库连接串仅应存在于部署环境变量；提交前运行 CI 的 Gitleaks 扫描。
- 请控制抓取频率，优先读取缓存；遇到 429、验证码或供应商明确禁止时，应停止回源并标注数据缺口，而不是绕过限制。

## 生产使用提醒

- 进程内缓存与限流适合单机/本地。多副本部署应替换为 Redis、API 网关或其他共享实现。
- `GET /api/health/sources` 仅反映进程上次调用后的观测结果，不等价于供应商可用性承诺。
- PostgreSQL 是持久化所需组件；无 `DATABASE_URL` 时服务会使用内存仓储，重启后内容会丢失。
- 本项目不应被用于自动下单、代客理财或规避市场/平台规则。
