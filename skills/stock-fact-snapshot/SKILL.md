# 个股事实快照

当需要对某一只 A 股做研究、解释、筛选结果复核或为多个 Agent 提供一致输入时，先建立事实快照。

1. 用户只给名称、简称或模糊描述时，先调用 `search_stock`，让用户确认唯一代码；不要猜测同名或近似证券。
2. 已有明确 6 位代码时，调用 `get_stock_fact_snapshot`。
3. 使用快照中的 `facts` 作为事实输入，以 `evidence[].evidenceId` 绑定每个重要判断；在结果中保留报告期、来源、抓取时间、验证等级与 `dataGaps`。

快照包含行情、可取得的财务与趋势、技术输入、公告及来源元数据。它不包含 AI 结论、目标价、估值判断或交易建议；这些必须由后续模块在已有证据范围内解释。

若某类数据缺失，只说明其不能支持的判断，不用其他字段推断或伪造该类数据。若调用发生在独立 MCP 部署而非产品服务内，工具可能只返回实时行情并在 `dataGaps` 标明原因。
