# 市场观察

当用户想了解当前 A 股整体状态、三大指数、市场广度、热点或领涨领跌板块时，调用 MCP 工具 `get_market_observation`。

输出时把“市场状态”明确表述为当前数据的描述，而非未来判断。优先展示：

- 三大指数及涨跌幅；
- 市场广度、市场温度、领涨/领跌板块；
- 数据时间、来源质量与数据缺口。

若工具返回数据缺口，保留该信息；不要用缺失指标补造结论。不要把“指数偏强/偏弱”等状态写成买卖指令、收益承诺或后续行情预测。

若用户只问单只股票，改用 `stock-fact-snapshot`；若问题涉及事件原因，先取得市场观察，再按需检索可核验新闻或公告。
