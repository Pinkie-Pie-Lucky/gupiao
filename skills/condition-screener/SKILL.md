# 条件筛选

当用户要从 A 股中按一组可描述的条件建立研究候选池时，调用 MCP 工具 `screen_stocks`。工具由服务端配置的东方财富妙想能力执行，密钥不得出现在请求、输出或前端。

将用户原话作为 `query`。只有用户明确要求“重新查”“刷新”时，传入 `refresh: true`；否则使用服务端缓存，避免重复消耗外部接口。

输出中至少保留：

- 原始查询、妙想拆解出的条件和候选总数；
- 返回字段、数据时点、来源和实时/缓存状态；
- `dataGaps` 与“仅展示前 100 条”的边界。

候选仅表示满足筛选条件，不等于看多、买入建议、收益预测或风险已排除。若用户要判断单只候选，先使用 `stock-fact-snapshot` 建立一致的事实底座，再解释数据。

不要在本地臆测字段含义或自行拼接结果；用户编辑条件后，应将新的完整条件重新提交给 `screen_stocks`。
