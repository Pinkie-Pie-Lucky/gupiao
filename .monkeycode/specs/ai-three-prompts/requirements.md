# AI 市场分析三 Prompt 架构 — 需求文档

## 背景

当前泡泡看市的早报、原因解读、热点卡片等功能均为硬编码文本，无法根据每日市场变化动态更新。本需求引入三层 AI Prompt 流水线架构，将市场分析拆解为"理解 → 推理 → 表达"三步，配合 finnews skill 获取实时数据，实现每日动态 AI 早报。

## 架构总览

```
                        ┌────────────────┐
                        │  finnews skill │  获取今日市场原始数据
                        │  (东方财富/     │  （指数、板块、公告、新闻）
                        │   Yahoo/华尔街) │
                        └───────┬────────┘
                                │ JSON 结构化行情数据
                                ▼
              ┌──────────────────────────────────┐
              │         Prompt 1: 市场理解         │
              │        Market Understanding        │
              │                                    │
              │  输入: 原始行情数据                  │
              │  输出: 市场情绪 + Top3 主题 +        │
              │        重要事件 + 受影响板块         │
              └────────────────┬─────────────────┘
                               │ JSON
                               ▼
              ┌──────────────────────────────────┐
              │         Prompt 2: 因果推理         │
              │        Market Reasoning            │
              │                                    │
              │  输入: Prompt 1 输出 + 新闻 +       │
              │        数据上下文                    │
              │  输出: 事件→原因→板块→结果的因果链   │
              └────────────────┬─────────────────┘
                               │ 结构化因果链
                               ▼
              ┌──────────────────────────────────┐
              │         Prompt 3: 老师表达        │
              │        Market Teacher              │
              │                                    │
              │  输入: Prompt 1 + Prompt 2 输出     │
              │  输出: 小白可读的自然语言文本        │
              └────────────────┬─────────────────┘
                               │ 可读文本
                               ▼
                         ┌───────────┐
                         │  前端渲染  │
                         │  HomeTab  │
                         └───────────┘
```

## 功能需求

### FR-1：AI 老师每日早报

- **触发**：用户打开首页 / 每天首次进入
- **数据来源**：finnews skill 拉取当日行情 + 新闻
- **处理链路**：Prompt 1 → Prompt 2 → Prompt 3 串联调用
- **输出**：当日市场摘要（小白可读），替换当前硬编码早报文本

### FR-2：今日发生了什么（今日三大热点）

- **触发**：首页"今日热点"区域
- **数据来源**：finnews skill 拉取当日新闻 + Prompt 1 输出
- **处理链路**：Prompt 1 识别主题 → Prompt 2 建立因果链 → Prompt 3 翻译
- **输出**：3 张卡片，每张含事件 + 原因 + 影响，替换当前硬编码卡片

### FR-3：今日市场概览（非 AI）

- **触发**：首页市场概览区域（三大指数、板块涨跌、成交量）
- **实现**：后端规则引擎直接从 finnews 数据计算涨跌幅、排序板块，不用 AI
- **输出**：结构化行情数据，前端渲染

## 各 Prompt 详细设计

### Prompt 1：市场理解（Market Understanding）

**职责**：从原始行情数据中提取今日核心交易逻辑。不总结所有新闻，只找出真正在驱动市场的因素。

**System Prompt：**

```text
你是一名资深市场分析师。你的任务不是总结所有新闻，而是找出今天真正影响市场的核心交易逻辑。

请遵循以下原则：
1. 优先依据市场数据（指数、板块涨跌幅、成交额变化）判断热点
2. 新闻仅作为解释依据，不要因为新闻数量多就认为影响大
3. 输出今天最重要的 3 个市场主题
4. 判断市场情绪（乐观 / 中性 / 谨慎）
5. 不预测未来，只描述今天市场正在交易什么

输出严格 JSON 格式，不可夹带任何解释或评论：
{
  "marketSentiment": "乐观" | "中性" | "谨慎",
  "top3Themes": [
    {
      "theme": "主题名称（如 AI算力全线领涨）",
      "confidence": "高" | "中" | "低",
      "evidence": "支撑该主题的数据证据"
    }
  ],
  "keyEvents": [
    {
      "event": "事件描述",
      "impact": "对市场的影响",
      "source": "新闻来源"
    }
  ],
  "affectedSectors": [
    {
      "sector": "板块名称",
      "changePercent": "涨跌幅（如 +4.32%）",
      "reason": "涨跌原因一句话"
    }
  ]
}
```

**输入来源**：finnews skill 返回的当日行情数据（指数、板块涨跌、成交量、涨幅 Top 股）

---

### Prompt 2：因果推理（Market Reasoning）

**职责**：基于市场理解结果，建立可验证的因果链。核心原则是"宁可证据不足，也不编造因果关系"。

**System Prompt：**

```text
你是一名财经逻辑分析师。请根据市场数据、新闻和已有知识，建立最合理的因果链。

要求：
1. 因果必须有依据，不允许猜测
2. 如果存在多个可能原因，请按影响程度排序
3. 如果证据不足，请明确说明"不确定"
4. 输出事件 → 原因 → 板块 → 结果，不输出投资建议
5. **宁可回答"证据不足"，也不要编造因果关系** ← 这条最关键

输出格式（每个主题一条因果链）：

事件：AI服务器全球订单超预期增长
原因：北美云厂商Q2资本开支同比+45%，带动算力硬件需求
影响板块：AI算力、光模块、服务器
市场结果：AI算力板块今日上涨5.2%，成交额环比+87%
确定性：高
```

**输入来源**：
- Prompt 1 输出的 `top3Themes`、`keyEvents`、`affectedSectors`
- finnews skill 返回的新闻原文（作为证据校验）

**输出格式**：

```json
{
  "causalChains": [
    {
      "theme": "对应的 Prompt 1 主题",
      "event": "触发事件",
      "reason": "原因分析",
      "affectedSectors": ["板块1", "板块2"],
      "marketResult": "市场表现数据",
      "certainty": "高" | "中" | "低" | "不确定"
    }
  ]
}
```

**关键设计**：
- `certainty: "不确定"` 是合法输出，当数据不足以支撑因果关系时直接输出
- 这条约束可以显著降低 AI 幻觉

---

### Prompt 3：老师表达（Market Teacher）

**职责**：将专业分析结果翻译成投资小白能理解的日常语言。

**System Prompt：**

```text
你是一位帮助投资小白成长的财经老师。请把分析结果翻译成普通人能理解的话。

要求：
1. 一句话原则 — 能用一句话说清楚就不用两句
2. 保留关键数字 — 涨跌幅、成交额等核心数据必须保留
3. 尽量不用专业术语 — 如果必须出现，同时用括号解释（例：主力资金流出指大机构在卖出）
4. 不制造焦虑，不给买卖建议
5. 目标是帮助用户理解，而不是预测市场

风格参考：
  "今天AI板块涨了5.2%，因为美国几大科技公司砸钱建AI数据中心，国内的光模块、服务器公司接到了大订单。
   但注意，下午有大资金在卖AI股票，说明部分机构觉得现在价格偏高了。
   半导体板块今天跌了0.8%，暂时没看到明显利空，属于正常波动。"
```

**输入来源**：Prompt 1 的 `marketSentiment` + `top3Themes` + Prompt 2 的 `causalChains`

## 后端 API 设计

### `POST /api/morning-report`

串联调用 Prompt 1 → 2 → 3，生成完整早报。

**流程：**

```
1. 调用 finnews skill 获取当日行情数据
2. 构造 Prompt 1 输入（行情数据 JSON）
3. 调用 Gemini → 获得 Market Understanding JSON
4. 构造 Prompt 2 输入（P1 输出 + 新闻原文）
5. 调用 Gemini → 获得 Causal Chains JSON
6. 构造 Prompt 3 输入（P1 + P2 输出）
7. 调用 Gemini → 获得可读文本
8. 返回 { report, themes, sentiment, timestamp }
```

**请求：**

```http
POST /api/morning-report
Content-Type: application/json

{}
```

**响应：**

```json
{
  "sentiment": "乐观",
  "summaryText": "今天AI板块涨了5.2%，因为...",
  "hotThemes": [
    {
      "title": "AI算力全线领涨",
      "reasonText": "北美云厂商加大AI投资...",
      "causalChain": "事件 → 原因 → 板块 → 结果",
      "affectedSectors": ["AI算力", "光模块"]
    }
  ],
  "cautiousNotes": ["下午主力资金高位流出，注意短线回调"],
  "timestamp": "2026-07-16T09:30:00+08:00"
}
```

## 与现有功能的对应关系

| 现有功能 | 当前实现 | 新方案 |
|----------|---------|--------|
| AI 老师每日早报 | 硬编码文本 | Prompt 1+2+3 串联 |
| 早报原因解读 | 硬编码三因素卡片 | Prompt 2 因果链 |
| 今日发生了什么 | 硬编码三张卡片 | Prompt 1+2+3 |
| 今日市场概览 | `data.ts` 硬编码 + `Math.random()` 模拟 | finnews skill + 规则引擎（不用 AI） |
| 数据获取 | 无真实数据源 | finnews skill（东方财富 + Yahoo + 华尔街见闻） |

## 验收标准

- [ ] 打开首页后，早报文案根据当日市场数据动态生成，非硬编码
- [ ] 三大热点卡片每张包含事件、原因、影响三要素
- [ ] 因果链中 `certainty: "不确定"` 的场景下不编造原因
- [ ] 市场概览数据来自 finnews skill 真实行情，不使用 `Math.random()` 模拟
- [ ] 老师表达文案中专业术语附带白话解释
- [ ] 每次 AI 调用之间串行执行，避免并发猛拉 API
